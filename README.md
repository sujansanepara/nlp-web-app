# NLP Web App

A simple NLP web application built with Flask that allows users to perform Sentiment Analysis on text.

## Features

- User Registration
- User Login
- Sentiment Analysis using API
- Flask based backend
- JSON based database

## Tech Stack

- Python
- Flask
- HTML
- API-Ninjas

## Installation

### 1. Clone the repository

git clone https://github.com/yourusername/nlp-web-app.git

### 2. Install dependencies

pip install -r requirements.txt

### 3. Add API Key

Create a .env file and add your API key

API_KEY=your_api_key_here

### 4. Run the application

python app.py

Open in browser

http://127.0.0.1:5000


## Project Structure

app.py → main flask app  
api.py → sentiment api  
db.py → json database logic  
templates → html files
